Web search (optional)

The coach can look things up instead of guessing: agent abilities and patch changes when you ask the coach, KovaaK's playlists and share codes on the Aim page. Answers show the pages they used.

DuckDuckGo needs no setup, but it has no official search API and blocks a server for a while when it searches a lot. SearXNG is free and stays on your own server. Claude's search costs US$ 10 per 1,000 searches plus the tokens (counted in the Claude budget).

Backups

Every night from 04:00: the database, players, teams, notes, strats and reports in one .tar.gz. Left out: the match cache, VODs and clips (they can be loaded or cut again). Restore: stop valcoach, unpack the archive into the data folder, start it again.

Full path on this server. Empty = inside the data folder, which doesn't help if the disk dies: use your NAS (e.g. /mnt/nas/valcoach-backups).
The newest ones stay, older ones are deleted.
